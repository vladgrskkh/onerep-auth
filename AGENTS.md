# onerep-auth

Authentication and user profile service for OneRep gym training app.

## Stack
- Go 1.26+, PostgreSQL 16, Redis 7

## Commands
```bash
make run          # Start server on :8080
make test         # Run all tests
make lint         # golangci-lint run
make tools        # Install dev tools (golangci-lint, goose, swag, mockery)
make mock         # Regenerate mocks with mockery
make swagger      # Regenerate OpenAPI docs
make migrate-up   # Apply migrations
make migrate-down # Rollback migrations
```

## Architecture
Domain-based layered structure with CSP (Consumer-defined interfaces):

```
cmd/server/              # Entry point
internal/
  domain/
    auth/                # Auth entities, value objects, errors
    user/                # User entities
  service/
    auth/                # AuthService, OAuthService + consumer interfaces
    user/                # UserService
  handler/
    auth/                # Auth HTTP handlers, error mapper, DTOs
    user/                # User HTTP handlers, error mapper, DTOs
  infrastructure/
    auth/
      postgres/          # UserRepo, OAuthAccountRepo
      redis/             # TokenStore
      jwt/               # TokenManager, Claims
      crypto/            # PasswordHasher
      oauth/             # Google adapter
  application/           # App wire-up (options pattern), route registration
  config/                # Config with caarlos0/env
  handler/               # Shared HTTP utilities: response, context, middleware
```

## HTTP error contract
All errors return a structured body:
```json
{
  "error": {
    "code": "INVALID_CREDENTIALS",
    "message": "invalid credentials",
    "user_message": "The email or password you entered is incorrect",
    "type": "user_error" | "system_error"
  }
}
```
Each domain has its own error mapper in `handler/<domain>/error_mapper.go`.

```bash
# Install tools + run
make tools

```

## ISP rule
Interfaces are declared where they are consumed (service/, handler/), not in infrastructure/.
No central interfaces.go file. Each service declares only the methods it needs.

## Mock generation
Mocks are generated by mockery into `internal/service/auth/mocks/*.gen.go`:
```bash
make mock
```
